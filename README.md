二、 兩大主要投資策略體系
本戰情室採用華爾街頂級避險基金的**「核心 ＋ 衛星」雙軌制**：

🛡️ 策略一：【核心底倉】長線價值投資與金字塔定期定額 (佔資金 70%~80%)
操作哲學：尋找具備「寬廣經濟護城河」與「跨週期成長」的產業霸主或大盤指數 ETF。
三大估值區間精算法：
💎 【便宜逢低加碼區】：股價回測年線或估值超跌，擴大扣款 1.5~2 倍或單筆重砲進場。
⚖️ 【合理定期定額區】：維持紀律每月固定扣款，平滑持股成本。
⚠️ 【昂貴過熱警戒區】：股價乖離過大，暫停單筆追高，僅維持定期定額或收割部分利潤。
零股小資平滑法：即使是 1,000 元以上的高價股（如聯發科、世芯-KY），也能透過永豐金 1 元手續費優惠，以「盤中零股」無負擔建倉。
⚡ 策略二：【衛星衝刺】三維合流 5~7 天高動能波段交易 (佔資金 20%~30%)
操作哲學：只在「外在總經順風 ＋ 內在大盤放量 ＋ 個股型態突破」三維合流時揮棒。

🎯 嚴格持股週期：持股僅 5 ~ 7 個交易日，絕不斷頭凹單成「長期套牢」。
